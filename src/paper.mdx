Ego-view RGB, side-view RGB, language and navigation commands condition the vision-language backbone. Robot state and depth are encoded for the flow-matching action expert, which outputs a 24-step chunk of 25-dimensional planner commands. So the robot runs the task alone in batches of 10, and each run is scored on where the box ends up. Reinforcement learning uses the scores to pick a better starting noise for each plan. The copied model and the controller stay as they are.</p>
